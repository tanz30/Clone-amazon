# Amazon Website Clone 🛒

## Description
This project is a static front-end user interface clone of the Amazon India website. It was developed to practice and demonstrate fundamental web development skills, specifically focusing on page layout, structural design, and CSS styling. The clone features a detailed navigation bar, a sidebar for deals and filtering options, a main product grid showcasing aesthetic items, and a comprehensive footer. This project serves as a practical, hands-on application of core front-end programming principles built during Computer Science and Engineering coursework.

## Features
*   **Custom Navigation Bar:** Includes functional links mimicking Amazon's primary navigation, a search input field, and categorized quick links (Fresh, Prime Video, Sell, etc.).
*   **Product Grid & Hover Effects:** Displays a gallery of product images with interactive CSS hover effects (smooth scaling and border highlighting) to enhance user experience.
*   **Sidebar Layout:** A left-hand sidebar built with Flexbox containing mock filtering options like "Delivery Day," "Free Shipping," and "Pay On Delivery."
*   **Structured Footer:** A multi-column footer containing essential Amazon links categorized into sections like "Get to Know Us," "Connect with Us," and "Let Us Help You."

## Tech Stack
*   **HTML5:** Used for semantic structuring of the web page (headers, main content, footers, lists).
*   **CSS3:** Utilized for styling, positioning (Flexbox, inline-blocks), custom color palettes, and hover transitions.

## Installation & Usage
1. Clone this repository to your local machine.
2. Ensure both the HTML file and `styles.css` are located in the same directory.
3. Open the HTML file in any modern web browser to view the website.
